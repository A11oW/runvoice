# Выбор моделей распознавания

В «Распознавании» сначала выбирается технология, затем модель.
Каталог whisper.cpp всегда раскрыт: у каждой отсутствующей модели есть кнопка
«Скачать». Выбрать модель можно после скачивания и проверки. Основной каталог
содержит только модели выбранной технологии. Резервный Whisper для FluidAudio
открывается в отдельном окне. Скачивание не меняет сохранённый выбор;
применить модель можно кнопкой «Сохранить» в основном окне настроек.

## С чего начать

| Задача | Что попробовать |
|---|---|
| Повседневная русско-английская диктовка | Whisper Large v3 Turbo Q5_0; сравнить «Русский» и «Авто», использовать технический словарь |
| Сравнение точности Whisper | Large v3 Q5_0 либо полный Large v3; потребуется больше времени обработки |
| Intel или экономия памяти | Small Q5_1; затем Medium Q5_0 для сравнения качества |
| Apple Silicon, приоритет качества FluidAudio | Parakeet Ultra с языком «Авто»; сравнить с Whisper на своём голосе |
| Эксперимент с IT-терминами внутри русской речи | Whisper Turbo RU/EN Code-Switching Q8_0 либо FP16; проверить также обычный русский и английский |
| Потоковое распознавание | Nemotron Multilingual |
| Минимальный размер FluidAudio | Redux на CPU; учитывать более слабые результаты на русском и английском |
| Компактный вариант для экспериментов на GPU | Phonon-2.5 |

Это рекомендации по выбору кандидатов. Поддержка двух языков не гарантирует
точность английских названий внутри русской фразы. Для сравнения используйте одну
запись, язык «Авто» и сначала отключите AI-правку, чтобы видеть результат ASR.
Затем оцените обычную работу с AI и словарём.

## Whisper через whisper.cpp

В каталоге 17 вариантов. Базовые модели многоязычные, включая русский и английский;
донастройки RU/EN требуют отдельного сравнения качества обычной английской речи.
Доступные файлы и форматы проверяются по [каталогу whisper.cpp](https://huggingface.co/ggerganov/whisper.cpp).
Загрузка каждого файла проверяется SHA-256.

| Семейство | Полный размер | Квантованные варианты |
|---|---:|---|
| Tiny | 78 МБ | Q5_1 — 32 МБ |
| Base | 148 МБ | Q5_1 — 60 МБ |
| Small | 488 МБ | Q5_1 — 190 МБ |
| Medium | 1.53 ГБ | Q5_0 — 539 МБ |
| Large v2 | 3.09 ГБ | Q5_0 — 1.08 ГБ |
| Large v3 | 3.10 ГБ | Q5_0 — 1.08 ГБ |
| Large v3 Turbo | 1.62 ГБ | Q5_0 — 574 МБ; Q8_0 — 874 МБ |
| Large v3 Turbo RU/EN Code-Switching · экспериментальная | FP16 — 1.62 ГБ | Q8_0 — 874 МБ |

Turbo использует сокращённый декодер и ориентирован на скорость.
Полный Large v3 полезен для сравнения точности при большем времени обработки.
[Описание Turbo от OpenAI](https://huggingface.co/openai/whisper-large-v3-turbo).
Q5/Q8 сокращают размер весов; скорость зависит от оборудования и реализации.
[Квантование в whisper.cpp](https://github.com/ggml-org/whisper.cpp#quantization).

### Донастройка Whisper для RU/EN

[coriollon/whisper-large-v3-turbo-russian-codeswitch](https://huggingface.co/coriollon/whisper-large-v3-turbo-russian-codeswitch)
обучалась на русских фразах с английскими техническими терминами, например
`Python`, `GitHub` и `Docker`. Автор сравнивает её со своей русской донастройкой,
а не с исходным OpenAI Turbo. Обучение использовало синтетическую речь и 53 термина;
опубликованы регрессии на части чисто русских тестов. Результат на неизвестных
терминах, обычном английском и живом голосе нужно проверять отдельно.

Runvoice скачивает [GGML-экспорт landco11](https://huggingface.co/landco11/coriollon-whisper-large-v3-turbo-russian-codeswitch-f8-f16)
с закреплённой ревизией и SHA-256. Он работает в существующем whisper.cpp,
без дополнительной технологии. Установленная модель сохраняет пометку
«экспериментальная». Автовыбор её пропускает, явный выбор пользователя учитывается.

## FluidAudio на Apple Silicon

Все модели ниже доступны отдельными кнопками скачивания, используют локальный
Core ML и поддерживают русский и английский. Размеры приблизительные.

| Модель | Загрузка | Назначение и ограничения |
|---|---:|---|
| Nemotron Multilingual 0.6B | ≈633 МБ | Настоящий потоковый ASR; усиление технических терминов при декодировании |
| Parakeet TDT v3 0.6B | ≈500 МБ | Базовый многоязычный вариант для сравнения |
| Parakeet Ultra 0.6B | ≈630 МБ | Кандидат на лучшее качество: по тестам FluidAudio точнее v3 при близкой скорости |
| Parakeet Redux 0.6B | ≈220 МБ | Экономия места, энкодер на CPU; по тестам разработчика уступает v3 на русском и английском |
| Phonon-2.5 0.6B | ≈290 МБ | Экспериментальный многоязычный вариант с GPU-энкодером |

Сравнения разработчика: [Ultra](https://github.com/FluidInference/FluidAudio/blob/main/Documentation/ASR/ParakeetUltra.md),
[Redux](https://github.com/FluidInference/FluidAudio/blob/main/Documentation/ASR/ParakeetRedux.md),
[Phonon-2.5](https://github.com/FluidInference/FluidAudio/blob/main/Documentation/ASR/Phonon25.md).
Эти тесты не заменяют отдельную проверку смешанной русско-английской речи.

У Parakeet и Phonon предварительный текст строится по коротким окнам, итог —
по полной записи. Для Redux выбран CPU-энкодер: он обходит несовместимость
GPU с LUT2 на части macOS и многоминутную первую компиляцию ANE.
Phonon-2.5 использует GPU-энкодер. Первый прогрев может быть дольше последующих запусков.
Словарь у этих моделей учитывается через AI-правку.

У Parakeet, Ultra, Redux и Phonon подсказка «Русский» включает фильтр кириллицы,
который может заменять английские токены. «Авто» отключает это ограничение.
Для смешанной речи у этих моделей используйте «Авто».
[Фильтр алфавита FluidAudio](https://github.com/FluidInference/FluidAudio/blob/main/Documentation/ASR/TokenLanguageFilter.md).
У Whisper параметр языка устроен иначе: для преимущественно русской речи с
английскими названиями имеет смысл сравнить «Русский» и «Авто».

Технология FluidAudio доступна на Apple Silicon с macOS 15+. На Intel используется
whisper.cpp. Свой файл Whisper можно добавить через «Добавить файл…»;
список внешних моделей и папок сохраняется.

## Имеет ли смысл другой движок

whisper.cpp и FluidAudio исполняют совместимые веса; качество зависит от модели,
её преобразования, подсказок и декодирования. Сам по себе переход на другой
runtime не означает улучшение точности.

**MLX Audio с Qwen3-ASR 1.7B** — кандидат для отдельного исследования, в Runvoice
не включён. Qwen поддерживает русский, английский и контекст с терминами.
В отчёте разработчика он опережает Large v3 на части многоязычных наборов, но
уступает на полном наборе FLEURS из 30 языков. Эти результаты не доказывают
преимущество на русских предложениях с английскими названиями.
[Отчёт Qwen](https://arxiv.org/html/2601.21337v1),
[Swift-реализация MLX Audio](https://github.com/Neywa-Labs/mlx-audio-swift).
Плюсы — новые модели и контекст до распознавания; затраты — GPU, память,
дополнительные зависимости и упаковка Metal. Для оценки точности разумнее
начать с моделей Whisper в существующем движке.

Другие локальные кандидаты:

- [Voxtral Realtime](https://huggingface.co/mistralai/Voxtral-Mini-4B-Realtime-2602)
  поддерживает русский и английский и предназначен для потокового ASR. Это более
  крупная модель; заявленная алгоритмическая задержка не равна времени ответа на Mac.
- [Nemotron Unified](https://huggingface.co/nvidia/nemotron-labs-unified-asr-0.6b)
  объединяет потоковое и полное распознавание 25 языков. Требует отдельной проверки
  смешанной речи и интеграции; текущий пункт Nemotron использует другую модель.
- [GigaAM Multilingual](https://huggingface.co/ai-sage/GigaAM-Multilingual)
  ориентирован на русский и ряд других языков, но английский слабее в опубликованном
  сравнении. Русскоязычная линейка GigaAM v3 не заменяет многоязычный Whisper.
- [Cohere Transcribe](https://huggingface.co/CohereLabs/cohere-transcribe-03-2026)
  не поддерживает русский; авторы отмечают нестабильность смешанной речи.

Воспроизводимая процедура сравнения — в [тест-плане](testing.md#сравнение-моделей-asr).
Результаты конкретных прогонов хранятся только в [CHANGELOG](../CHANGELOG.md).
