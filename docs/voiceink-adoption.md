# Что перенесено из подходов VoiceInk

Runvoice 1.1.1 требует macOS 15+. Реализация написана в Runvoice самостоятельно;
исходные файлы VoiceInk не переносились. В качестве отдельной зависимости используется
[FluidAudio](https://github.com/FluidInference/FluidAudio), revision
`ee78635d23d52379117554ba72358b65a0612447` из исследованной версии VoiceInk.
Лицензии FluidAudio и fastcluster включаются в arm64-бандл.

| Подход | Реализация Runvoice |
|---|---|
| Нативный захват вместо отдельного FFmpeg | входной AUHAL с выключенным выходом, выбор Core Audio input по UID, пул буферов; файловый I/O и ресемплинг в отдельной очереди |
| Один источник аудио | Из одного PCM идут WAV, уровень микрофона и ASR; второй микрофон для эквалайзера не открывается |
| Распознавание во время записи | Nemotron Multilingual, полный словарь multilingual, фрагменты 1120 мс, FluidAudio / Core ML |
| Сохранение модели в памяти | Помощник RunvoiceASR остаётся запущенным между диктовками; Whisper держит свой сервер |
| Словарь терминов | Prompt Whisper, decode-time bias Nemotron и предпочтительные написания в AI-промпте |
| Полноценный прогрев | Синтетическая речь при старте, сохранении и пробуждении; без истории и вставки |
| Быстрое завершение | Немедленная остановка preview, дренирование записанных буферов и конвертера; finish потока вместо повторного полного ASR |
| Резервный результат | При ошибке / пустом результате / таймауте потока весь WAV обрабатывает выбранный Whisper |

Используется [Nemotron 3.5 ASR Streaming Multilingual 0.6B Core ML](https://huggingface.co/FluidInference/Nemotron-3.5-ASR-Streaming-Multilingual-0.6b-CoreML).
Всегда загружается вариант `multilingual/1120ms`, включая русский и английский;
выбор English не заменяет его вариантом Latin с урезанным словарём.
Модели загружаются отдельно от приложения. Установочный маркер публикуется после
успешной загрузки Core ML. Повторная проверка/скачивание и отмена доступны в настройках.

На Intel остаётся Whisper на CPU. Whisper пока работает через встроенный сервер:
переход на прямой C API не входил в эти изменения. Его preview остаётся ограниченным
окном последних шести секунд, а итоговый проход охватывает всю запись. Частичные
Whisper-гипотезы не используются как окончательный текст.

Профиль AI и выбранный Whisper автоматически не меняются. Новый движок и словарь
выбираются пользователем. Нативный WAV и временный текст удаляются после обработки
или отмены. Финальное распознавание и постобработка по-прежнему выполняются
последовательно: время ответа AI входит в задержку до вставки.

Протокол проверок и ограничения — [testing.md](testing.md#22-нативный-аудиотракт-и-потоковый-движок--12-ноября-2026).

В 1.1.1 AVAudioEngine заменён входным AUHAL: аппаратная регрессия выявила
пустые записи и падение AVAudioIOUnit при освобождении движка. Повторные проверки
микрофона выполняются на настоящем устройстве через `--test-microphone`.
