description: "Выпустить версию через GitHub Actions"
agent: build
---

Выпуск: $ARGUMENTS

1. Убедись, что `06-verification.md` закрыт и G6 подтверждён.
2. Убедись, что выполнены минимальные проверки из `AGENTS.md`: сборка обеих
   архитектур, `codesign --verify --deep --strict`, DMG и `hdiutil verify`,
   smoke-набор.
3. Подними оба номера версии в `app/Info.plist` — `CFBundleShortVersionString`
   и `CFBundleVersion` должны совпадать — и перенеси изменения из
   «Не выпущено» `CHANGELOG.md` в раздел с этим номером (подробности в
   `docs/updates.md`).
4. Закоммить, запушь и создай тег `v<версия>`. Workflow **Release Runvoice**
   в GitHub Actions соберёт обе архитектуры, прогонит тесты, подпишет
   `Runvoice Local Signing` и создаст черновик релиза.
5. Покажи сводку: версия, что вошло в выпуск, какие шаги остаются вручную —
   одобрить окружение `release` и опубликовать черновик как Latest.

Не создавай тег, не пушь и не публикуй релиз без явного подтверждения
пользователя. Опубликование черновика — отдельное явное действие.
